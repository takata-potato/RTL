# 01_lexical — 文字・数値・識別子を読む

同じ値の4通りの書き方と、空白で終わるエスケープ識別子。

```bash
make learn LAB=01_lexical
```

| 見るもの | 内容 |
| --- | --- |
| 期待する結果 | 2進/8進/10進/16進が42。1stepはこのTBでは1ps。 |
| 1か所変える実験 | 8'h2a を 8'h2b に変えると最初の照合が失敗する。 |
| 文法 | 識別子 / エスケープ識別子 / 数値リテラル / 時間リテラル / 文字列 / 属性 / __FILE__ / __LINE__ |
| 仕様書 | §5、§22.13（詳細なページは索引から開く） |
| 実験形式 | sim |
| Icarus対象 | なし。Xcelium向け、または資料・外部機能の実験。 |

Icarus 11は#1stepを解釈できないため、この実験の実行対象に含めない。29_clockingでも#1stepを扱う。

コードはこのフォルダーのファイルを編集します。各`CHECK`が観察点、`LAB_PASS`が完走の印です。
文法欄には発展課題も含まれます。コードで実際に使ったトークンは全体索引の「コードあり」で検索できます。
