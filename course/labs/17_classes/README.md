# 17_classes — class・ハンドル・コピー

ハンドル代入は同じオブジェクトを指し、new 元ハンドルは浅いコピー。

```bash
make learn LAB=17_classes
```

| 見るもの | 内容 |
| --- | --- |
| 期待する結果 | alias経由の変更は元にも反映、newによるコピーのintは独立。 |
| 1か所変える実験 | childもコピーしたいときに、浅いコピーと自作deep copyの差を考える。 |
| 文法 | class / new / this / static property / static method / const / null / shallow copy |
| 仕様書 | §8.1、§8.2、§8.3、§8.4、§8.5、§8.6、§8.7、§8.8、§8.9、§8.10、§8.11、§8.12、§8.19、§8.29（詳細なページは索引から開く） |

| Icarus対象 | なし。Xcelium向け、または資料・外部機能の実験。 |



コードはこのフォルダーのファイルを編集します。各`CHECK`が観察点、`LAB_PASS`が完走の印です。
文法欄には発展課題も含まれます。コードで実際に使ったトークンは全体索引の「コードあり」で検索できます。
