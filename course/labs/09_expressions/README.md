# 09_expressions — 幅・符号・演算子・ストリーミング

同じビット列でも符号型と切り出しによって右シフトが変わる。

```bash
make learn LAB=09_expressions
```

| 見るもの | 内容 |
| --- | --- |
| 期待する結果 | -4>>>1は-2。部分選択後の>>>は0x7e。streamingで0x1234のバイトが0x3412。 |
| 1か所変える実験 | 8bitの切り出しに$signedを付けて符号付きへ戻す。 |
| 文法 | 算術 / 比較 / 論理 / ビット演算 / リダクション / 連結 / 繰返し連結 / streaming / inside / >> / >>> / indexed part-select / let |
| 仕様書 | §11、§6.24（詳細なページは索引から開く） |
| 実験形式 | sim |
| Icarus対象 | なし。Xcelium向け、または資料・外部機能の実験。 |



コードはこのフォルダーのファイルを編集します。各`CHECK`が観察点、`LAB_PASS`が完走の印です。
文法欄には発展課題も含まれます。コードで実際に使ったトークンは全体索引の「コードあり」で検索できます。
